# ActeckSmart v1.8

Индикатор для **MetaTrader 5**: коррекционные зоны (КЗ), зигзаг 1-го и 2-го уровней, структура «продолженное движение» и зоны интересов покупателей/продавцов (Fib 38.2%), RSI HUD.

**Автор:** Евгений Ацтек
**Версия:** 1.8
**Файл:** `ActeckSmart.mq5`
**Рабочий таймфрейм расчёта:** всегда **M15** (независимо от ТФ графика)

> Версия в `#property version`, `AS_VERSION` и этом README должна совпадать.

### Изменения v1.8

- КЗ получает отдельное время подтверждения: до завершения ИКИ она не участвует в расчёте баланса и СПД.
- Первое направление ИКИ задаёт исходную КЗ. Новая КЗ противоположного направления допускается после закрытия ближайшей подтверждённой КЗ соответствующего типа.
- Диапазон баланса формируется только последними подтверждёнными верхней и нижней КЗ; подбор произвольной пары как запасной вариант удалён.
- Последние границы активного диапазона остаются видимыми, даже если они старше срока отображения неактуальной истории.
- Завершение СПД и повторный поиск баланса привязаны ко времени подтверждения встречной КЗ.
- Для завершённого СПД горизонтальный пунктир от конечного экстремума продолжается вправо от той же временной точки, что устраняет визуальный разрыв между наклонной и завершающей опорой.
- Состояние зоны обозначается цельной заливкой и меткой внутри прямоугольника; диагональная штриховка удалена.
- Включённый алерт не воспроизводится для всей исторической серии при каждом пересчёте.

### Откат истории ПД (как Sniper ↔ v1.1)

| Параметр | По умолчанию | Смысл |
|----------|--------------|--------|
| `InpSniperStyleHistory` | `true` | Сохранять линии, курсоры и зоны исторических ПД (режим Sniper) |
| `InpKeepObsoleteZones` | `true` | Зоны покупателей/продавцов у старых ПД не стираются |
| `InpHideObsoleteCM` | `true` | Только при `InpSniperStyleHistory=false` (полное поведение v1.1) |

**Откат к логике v1.1:** поставьте `InpSniperStyleHistory = false`.

### Зоны интересов — жизненный цикл по ликвидности

| Состояние | Критерий | Отображение |
|-----------|----------|-------------|
| **FRESH** | цена ещё не заходила в зону | цельная полупрозрачная заливка и метка `НЕ ТРОНУТА` |
| **TOUCHED** | бар зашёл в зону, но не пробил дальнюю границу | цельная заливка с меньшей непрозрачностью и метка `КАСАНИЕ` |
| **BROKEN** | тень ушла за дальнюю границу (ликвидность снята) | не рисуется по умолчанию (`InpZoneHideBroken=true`); если отображение включено, получает метку `ПРОБИТА` |

Состояние больше не кодируется расходящимися диагональными линиями. Внутри прямоугольника отображается компактная метка состояния с уровнем `38.2%`. `InpZoneAlpha` и `InpZoneTouchedAlpha` задают непрозрачность заливки (0 — полностью прозрачная, 255 — полностью непрозрачная).

Покупатели (ПД вверх): пробой = Low ниже нижней границы зоны.  
Продавцы (ПД вниз): пробой = High выше верхней границы зоны.

### RSI HUD (правый верхний угол)

Непрозрачная белая панель (как Sniper): слева толстый мини-график, справа крупное число.  
Период 14. Цвет: зелёный (35–65), золотой (30–35 и 65–70), красный (<30 или >70).

Имя **ActeckSmart v1.8** в углу — системное (`INDICATOR_SHORTNAME`): клик → свойства / список / удалить. При удалении все объекты с префиксом `AS_` снимаются с графика (`ObjectsDeleteAll`).

## Установка

1. Скопируйте `ActeckSmart.mq5` в каталог данных терминала:
   - `File → Open Data Folder → MQL5 → Indicators`
2. В MetaEditor откройте файл и нажмите **F7** (Compile).
3. Убедитесь, что рядом появился `ActeckSmart.ex5`.
4. В MT5: `Navigator → Indicators → ActeckSmart` → перетащите на график.
5. Настройте **сдвиг времени брокера** (`InpBrokerGMTOffset`) относительно GMT, чтобы сессии совпадали с [investing.com Market Hours](https://ru.investing.com/tools/market-hours).

Рекомендуется тестировать на графике M15; на M1/M5/H1 разметка **не пересчитывается** — она всегда строится по закрытым свечам M15.

## Логика работы

### Критически важно

- Все расчёты идут через `CopyRates(_Symbol, PERIOD_M15, ...)` и `iTime(_Symbol, PERIOD_M15, ...)`.
- Перерисовка выполняется **только при появлении нового бара M15** (закрытие предыдущей свечи).
- При смене таймфрейма графика объекты сохраняют привязку ко времени M15 — визуально разметка «как на M15».

### Модуль 1 — Зигзаг 1-го уровня

Баровый алгоритм по High/Low (с учётом теней):

| Ситуация | Поведение |
|----------|-----------|
| Внутренний бар | Игнорируется |
| Внешний бар | Смотрим следующий бар; при обновлении Low — зигзаг на High внешнего, затем на Low следующего (и зеркально вверх) |
| Два внешних подряд | Средний бар игнорируется |
| Гэпы | Как обычные движения по High/Low |

По умолчанию **скрыт** (`InpShowZigZag1 = false`).

Зигзаг 1-го уровня использует локальный референсный бар. Особые случаи внешних баров следует сверять с приложенным графическим примером; алгоритм не является универсальным ZigZag и зависит от последовательности баров.

### Модуль 2 — Тенденции 2-го уровня и КЗ

- ИКИ считается подтверждённым, только если второй импульс обновил экстремум первого: для роста — выше предыдущего максимума при более высоком минимуме, для снижения — ниже предыдущего минимума при более низком максимуме.
- Первая подтверждённая тенденция задаёт исходную КЗ по её первому экстремуму. Следующая КЗ создаётся по подтверждённой ИКИ обратного направления. Уровень может быть пройден в ходе формирования этой ИКИ, до подтверждения второго импульса; отдельная повторная проверка «ближайшей КЗ» после подтверждения не блокирует создание зоны.
- Точка КЗ исторически привязана к экстремуму, но использовать её для баланса/СПД алгоритм начинает только с бара подтверждения ИКИ. Это предотвращает использование ещё не подтверждённой зоны в прошлом.
- Диапазон баланса — последние подтверждённые верхняя и нижняя КЗ. Если одной из границ нет или верхняя граница не выше нижней, диапазон не используется.
- Линия КЗ рисуется от экстремума вправо и **обрывается** при первом пересечении уровня свечой M15 после подтверждения КЗ.
- Подпись: `КЗ` + имя сессии (читаемый шрифт на белом фоне).

**Цвета КЗ по сессиям (по умолчанию):**

| Сессия | Цвет | GMT (investing.com) |
|--------|------|---------------------|
| New York | Red | 12:00–21:00 |
| London | Orange | 07:00–16:00 |
| Europe | Beige `C'245,222,179'` | 07:00–16:00 |
| Asia | DarkGreen | 21:00–08:00 |
| Australia | DodgerBlue | 21:00–07:00 |

При наложении сессий приоритет: **NY → London → Europe → Asia → Australia**. В текущих значениях Europe и London заданы одним и тем же интервалом; поэтому при стандартных настройках Europe не назначается (сработает London). Чтобы различать эти категории, укажите для них разные интервалы. Время не переключается автоматически на летнее/зимнее.

**Затухание (если `InpKeepHistory = false`):**

1. Актуальный день — полная яркость  
2. Через `InpFadeDays1` день — тусклее  
3. Через `InpFadeDays2` — ещё тусклее  
4. После `InpFadeDays2 + 1` календарных дней — удаление (при значениях по умолчанию, начиная с даты D+3).

Зигзаг 2-го уровня по умолчанию **скрыт**.

### Модуль 3 — Продолженное движение

1. Цена **закрывается** за пределами **актуального** диапазона баланса (пары КЗ текущего поколения).
2. Рисуется **горизонтальная пунктирная** опора на уровне пробитой КЗ (синяя вверх / красная вниз).
3. Наклонная линия начинается в точке пересечения временной координаты бара пробоя с ценой пробитой КЗ (границей баланса), а не с произвольного High/Low этой свечи; её конец обновляется по новому экстремуму.
4. Пока ПД активно — это **одна** структура. Пересечение старых КЗ от прошлых диапазонов **игнорируется**.
5. Новые КЗ по тренду не создаются, пока нет **ИКИ в обратном направлении** (PDF).
6. ПД: пробой баланса → наклонная → закрытие встречной КЗ. Цвета: **вверх — синий**, **вниз — красный**.
7. СПД завершается при подтверждении встречной КЗ; до этого экстремумы продолжают обновляться только по M15 High/Low.
8. Неактуальные ПД в режиме Sniper остаются на графике; старые структуры тускнеют и удаляются по настройкам срока хранения. При `InpSniperStyleHistory=false` можно скрывать старые линии и ограничить число видимых ПД.
9. **Зона интересов** — участок от непробитой КЗ до уровня Fib 38.2% между ней и пробитой границей. Состояния FRESH / TOUCHED / BROKEN различаются заливкой и текстовой меткой; BROKEN по умолчанию скрыта.
10. Пробитая КЗ — **сплошная толстая** линия цвета сессии.

## Примечание по этапу 1

Версия 1.8 — реализация разметки КЗ / баланса / продолженного движения для проверки на графиках. Сигналы на вход в сделки не реализованы. Несмотря на сверку с доступными PDF и схемами, точное совпадение с закрытым обучающим видео или оригинальным Sniper не заявляется; перед использованием необходима визуальная проверка на тестере/демо-счёте.
